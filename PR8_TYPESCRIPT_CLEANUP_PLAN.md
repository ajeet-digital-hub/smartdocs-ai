### Group 4 — Next.js 16 Route Params `Promise<>` Migration (P3 — ~64 errors)

- **Root cause**: Next.js 16 changed route params from `{ params: { id: string } }` to `{ params: Promise<{ id: string }> }`. The `.next/types/validator.ts` auto-generated checks fail against old handler signatures.
- **Affected files** (4 route files — 64 errors are in 2 auto-generated validator files):
  - `app/api/family-guardian/children/[id]/route.ts`
  - `app/api/family/schedules/[id]/route.ts`
  - `app/api/family/unlock-requests/[id]/route.ts`
  - `app/api/family/website-policies/[id]/route.ts`
- **Proposed fix**: Update handler signatures:
  ```ts
  // Before:
  export async function GET(_request: Request, { params }: { params: { id: string } })
  // After:
  export async function GET(_request: NextRequest, { params }: { params: Promise<{ id: string }> })
  ```
- **Risk**: 🟢 LOW — type signature change only, no runtime impact
