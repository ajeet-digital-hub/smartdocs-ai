# SmartDocs AI - Agent Knowledge Base

This document serves as the single source of truth for all services and capabilities available within the SmartDocs AI platform. The AI Agent uses this inventory for service discovery and tool routing.

**Last Updated:** 2026-07-31

---

## Service Inventory

### 1. Document Q&A

-   **Service Name**: Document Q&A
-   **Category**: PDF & Documents
-   **Description**: Answers user questions based on the content of a specific, uploaded document.
-   **Input**: A user query (string) and a document ID.
-   **Output**: A text answer grounded in the document's content, with page citations.
-   **Supported File Types**: PDF
-   **Supported Languages**: English, Hindi, Spanish, French, German (and others supported by the AI model).
-   **Required Plan**: Basic, Pro, Pro+
-   **Required Feature Flag**: `DOCUMENT_AI`
-   **Credit Usage**: 1 credit per question.
-   **Existing API/Tool**: `DocumentQATool`
-   **Implementation Status**: **IMPLEMENTED**
-   **Example User Requests**:
    -   "What does page 5 say about revenue?"
    -   "Find the section on market analysis in this document."
    -   "इस दस्तावेज़ में मुख्य निष्कर्ष क्या हैं?"

### 2. Document Summarization

-   **Service Name**: Document Summarization
-   **Category**: PDF & Documents
-   **Description**: Creates a concise summary of the content retrieved from an uploaded document.
-   **Input**: A user request for a summary and a document ID.
-   **Output**: A text summary of the document's content.
-   **Supported File Types**: PDF
-   **Supported Languages**: English, Hindi, Spanish, French, German (and others supported by the AI model).
-   **Required Plan**: Pro, Pro+
-   **Required Feature Flag**: `DOCUMENT_AI`
-   **Credit Usage**: 1 credit per summary request.
-   **Existing API/Tool**: `DocumentSummarizationTool` (used in a multi-step workflow with `DocumentQATool`).
-   **Implementation Status**: **IMPLEMENTED**
-   **Example User Requests**:
    -   "Summarize this PDF."
    -   "Give me the key points of this report."
    -   "इस PDF का सारांश बनाओ।"

### 3. General AI Chat

-   **Service Name**: General AI Chat
-   **Category**: AI Chat
-   **Description**: Provides answers to general knowledge questions, helps with writing tasks (emails, reports), and engages in conversation when no specific document or tool is required.
-   **Input**: A user query (string).
-   **Output**: A text answer generated by the AI model.
-   **Supported File Types**: N/A
-   **Supported Languages**: English, Hindi, Spanish, French, German (and others supported by the AI model).
-   **Required Plan**: All plans (Free plan has limits).
-   **Required Feature Flag**: `AI_CHAT`
-   **Credit Usage**: 1 credit per message.
-   **Existing API/Tool**: `generateAIResponse` (default path in orchestrator).
-   **Implementation Status**: **IMPLEMENTED**
-   **Example User Requests**:
    -   "What is cloud computing?"
    -   "Write an email to my manager asking for a day off."
    -   "Hello, how are you?"

### 4. Document Translation

-   **Service Name**: Document Translation
-   **Category**: Translation
-   **Description**: Translates the content of an entire document from a source language to a target language.
-   **Input**: A document ID and target language.
-   **Output**: Translated text content, page by page.
-   **Supported File Types**: PDF
-   **Supported Languages**: English, Hindi, Spanish, French, German (and others supported by the AI model).
-   **Required Plan**: Pro+
-   **Required Feature Flag**: `DOCUMENT_TRANSLATION`
-   **Credit Usage**: Varies by document size (per page/chunk).
-   **Existing API/Tool**: `DocumentTranslationTool`
-   **Implementation Status**: **IMPLEMENTED**
-   **Notes**: Translates the full text content of a document page by page. Does not yet produce a translated file download.
